## Gemini 生成提示词

生成一个基于 Three.js 与鼠标捕捉器的实时交互 3D 粒子系统。

要求：
1. 通过实时捕捉鼠标位置，与粒子模型进行交互
2. 提供多种预设的 3D 粒子模型（星云/烟花/土星/花朵等）
3. 粒子有辉光效果，五彩斑斓
4. 模型会根据旋转角度变化颜色色相
5. 提供颜色选择器和粒子密度调节滑块
6. 界面简洁现代，右下角全屏控制，左下角摄像头实时窗口
7. 背景粒子大量随机散布在深空中，增加空间纵深感
