## Google Gemini 生成提示词
按照下面
生成一个基于Three.js与鼠标捕捉器 的实时交互3D粒子系统。
要求:
1.通过实时捕捉鼠标位置，与粒子模型进行交互。例如:通过鼠标移动方向控制粒子模型的扩散与收缩;通过手移动位置控制粒子模型的旋转。
2.提供多种预设的3D粒子模型例如:星云/烟花/土星/花朵等，在界面右侧提供按钮可供选择。
3.粒子有辉光效果，五彩斑斓。
4.模型会根据旋转角度变化颜色色相。
5.提供颜色选择器调整粒子基础颜色，提供粒子密度调节滑块。
6.界面简洁现代，右下角有全屏控制按钮，画面左下角有摄像头实时窗口(可调整大小)。
7.背景粒子大量随机散布在深空中，增加空间纵深感，整体画面五彩斑斓。
